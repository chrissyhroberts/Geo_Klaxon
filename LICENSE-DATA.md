# Offline data licensing

`app/src/main/assets/world_countries.geojson` contains Natural Earth 1:110m administrative polygons (WGS84), extracted and re-encoded from the Natural Earth low-resolution dataset. Natural Earth data is public domain. Source: https://www.naturalearthdata.com/about/terms-of-use/ .

Geocoding requests, only when the user explicitly searches: Postcodes.io (https://postcodes.io/). Check its terms and data attribution requirements for any distribution; no API key is embedded.
